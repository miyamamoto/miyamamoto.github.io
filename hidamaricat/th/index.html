Sunny Spot Cat

แมวตัวน้อยที่อาศัยอยู่บนหน้าต่างของคุณ (Mac และ Windows)

  • ใช้ได้ฟรี
  • ไม่มีโฆษณา
  • ไม่เก็บข้อมูล

ทุกต้นชั่วโมง แมว ๆ จะมารวมตัวกัน

หนึ่งปีกับน้องแมว

งีบหลับ นวดแป้ง และเล่นสนุก กลีบดอกไม้ในฤดูใบไม้ผลิ ไฮเดรนเยียในวันฝนตก เทศกาลในฤดูร้อน ใบไม้ปลิวในฤดูใบไม้ร่วง และหิมะในฤดูหนาว เมื่อฤดูกาลเปลี่ยน ทิวทัศน์และการเล่นก็เปลี่ยนไปด้วย

คำถามที่พบบ่อย

  • เมนูอยู่ที่ไหน

    บน Mac ให้คลิกอุ้งเท้าบนแถบเมนู บน Windows ให้คลิกอุ้งเท้าบนแถบงาน (ถ้ามองไม่เห็น จะอยู่ใน “^”) หรือคลิกขวาที่แมว

  • ใช้งานอย่างไร

    เลือก “ลองดูวิธีใช้” ในเมนู แล้วจะมีคำแนะนำทีละขั้นตอน

  • มองไม่เห็นแมว

    ตรวจสอบว่าเปิด “เล่นบนหน้าต่าง” ในเมนูไว้แล้ว ถ้าไม่มีหน้าต่างเปิดอยู่ แมวจะนั่งอยู่บน Dock หรือแถบงาน

  • มีการเก็บข้อมูลไหม

    ไม่มี ทุกอย่างอยู่ในอุปกรณ์ของคุณเท่านั้น

  • มีค่าใช้จ่ายไหม

    ทุกฟีเจอร์ใช้ได้ฟรี ส่วน “สนับสนุน” นั้นไม่บังคับ มีทั้งแบบสนับสนุนครั้งเดียวและแบบรายปีที่ต่ออายุอัตโนมัติ (สมัครสมาชิก) หากต้องการยกเลิก บน Mac ทำได้ในการตั้งค่าบัญชี App Store และบน Windows ทำได้ที่ “บริการและการสมัครใช้งาน” ในบัญชี Microsoft

  • ใช้ได้กับคอมพิวเตอร์แบบไหน

    Mac ใช้ได้กับ macOS 13 ขึ้นไป (Apple silicon และ Intel) ส่วน Windows ใช้ได้กับ Windows 10 (เวอร์ชัน 1809) ขึ้นไป และ Windows 11

  • บน Windows เปิดขึ้นเองอัตโนมัติไหม

    ใช่ แอปจะเปิดขึ้นเองเมื่อลงชื่อเข้าใช้ ถ้าต้องการปิด ให้ใช้ “เปิดเมื่อลงชื่อเข้าใช้…” ในหน้าต่าง “เกี่ยวกับ Sunny Spot Cat” จากเมนู หรือไปที่ “การตั้งค่า → แอป → เริ่มต้นระบบ” ของ Windows

  • หาเวอร์ชัน Mac ได้ที่ไหน

    มีให้ดาวน์โหลดใน Mac App Store (ขณะนี้ยกเว้น App Store ในสหภาพยุโรปและจีนแผ่นดินใหญ่)
